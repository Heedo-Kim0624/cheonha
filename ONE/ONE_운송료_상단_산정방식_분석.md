# ONE 운송료 지급명세서 상단 산정 방식 분석

## 기준 파일

- 원본: `ONE/2605_4_CJ_ONE_정산(1.Dashboard)의 사본.xlsx`
- 원천 데이터: `취합B_(기사)`
- 단가 기준: `단가표`의 Type A 첫 번째 단가 블록
- 검증 대상: 기사별 `_B` 시트의 `운송료 외` 위쪽, 즉 `전체 운송료` 영역의 금액

## 핵심 결론

`취합B_(기사)`의 `합계` 컬럼을 그대로 더하면 기사별 `_B` 명세서의 상단 운송료 금액과 맞지 않는다.

원본 `_B` 명세서 상단 운송료 금액은 다음 방식으로 재계산되어 있다.

1. `취합B_(기사)`를 `일자 + 구분 + 수수료명칭 + SM + 주문번호` 기준으로 묶는다.
2. 같은 묶음의 행 수를 박스 수로 본다.
3. `추가박스 = max(박스 수 - 1, 0)`으로 본다.
4. `단가표` Type A 단가를 적용해 주문 그룹별 지급액을 다시 계산한다.
5. 기사별, 구분별, 수수료명칭별로 합산해 `_B` 시트의 상단 금액을 만든다.

## 취합B 합계와 명세서 금액이 다른 이유

`취합B_(기사)`의 `합계`는 명세서 지급액을 최종 계산한 값이 아니다. 예를 들어 `취합B_(기사)`의 `비고`에는 `모수:... / 착지단가:...` 형태의 원천 계산 흔적이 들어 있고, 이 금액을 단순 합산하면 `_B` 명세서 상단보다 크다.

검증 결과:

| 계산 방식 | `_B` 상단 운송료 대비 결과 |
|---|---:|
| `취합B_(기사).합계` 단순 합산 | 3,080,477원 초과 |
| 단가표 Type A + W1,2 날짜별 단가 + 종로구 가산 없음 | 금액 차이 0원 |

따라서 서버에서 원본 `_B` 명세서와 맞추려면 `취합B 합계`가 아니라 `단가표` 기반 재계산을 사용해야 한다.

## 적용 단가 규칙

### W1,2 공동배송

`단가표` 왼쪽의 날짜별 단가를 사용한다.

- 단가표에서 각 일자의 `공동배송 + 트레이더스` 총량을 기준으로 날짜별 단가가 계산되어 있다.
- 지급액은 `해당 일자 단가 * 박스 수`다.
- 즉 W1,2 공동배송은 착지당 1회 지급이 아니라, 박스 수만큼 날짜별 단가를 곱해야 원본 금액과 맞는다.

예:

```text
W1,2 공동배송 지급액 = sum(일자별 단가 * 주문 그룹의 박스 수)
```

### W1,2 트레이더스

`단가표` 왼쪽의 날짜별 단가를 사용한다.

```text
W1,2 트레이더스 지급액 = 날짜별 단가 + 추가박스 * 1,000원
```

여기서 추가박스는 `박스 수 - 1`이다.

## 종로구 200원 규칙

원본 `_B` 명세서의 상단 운송료 금액에는 `시군구 == 종로구`일 때 박스당 200원을 추가하는 규칙이 반영되어 있지 않다.

종로구 200원 가산을 적용하면 원본 명세서 상단 금액보다 커진다. 따라서 원본 파일과 완전 일치가 목표라면, 기사 지급명세서 상단 운송료 계산에는 종로구 200원 가산을 적용하면 안 된다.

## 검증 결과

`취합B_(기사)` 원천 데이터를 위 규칙으로 다시 계산해 원본 `_B` 시트의 `운송료 외` 위 금액과 비교했다.

결과:

```text
amount_diff_total = 0
abs_amount_diff = 0
```

즉, 운송료 외 항목을 제외한 상단 운송료 금액은 위 방식으로 완전히 일치시킬 수 있다.

단, 표시 수량에서 1건의 예외가 있었다.

| 기사 | 항목 | 계산 착지 | 원본 표시 착지 | 금액 |
|---|---|---:|---:|---:|
| 정승제 | W1,2 공동배송 | 473 | 487 | 일치 |

이 케이스는 금액은 일치하지만, 원본 `_B` 표시 수량이 주문 그룹 수가 아니라 박스 수처럼 들어간 흔적이 있다. 금액 산정 기준으로는 `W1,2 공동배송 = 날짜별 단가 * 박스 수`가 맞다.

## 서버 반영 방향

서버에서 원본과 맞추려면 다음을 반영해야 한다.

1. ONE 지급명세서 상단 운송료는 `source_amount` 합산이 아니라 단가표 기반 재계산 금액을 사용한다.
2. W1,2 공동배송/트레이더스 단가는 기사별 월 물량이 아니라 날짜별 전체 공동배송+트레이더스 물량으로 산정된 일자별 단가를 사용한다.
3. W1,2 공동배송은 박스 수만큼 날짜별 단가를 곱한다.
4. W1,2 트레이더스는 날짜별 단가 1회 + 추가박스당 1,000원을 더한다.
5. 기사 지급명세서 상단 운송료에는 종로구 200원 가산을 적용하지 않는다.
