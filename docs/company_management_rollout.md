# 회사 관리 기능 배포/검증 메모

## 목표
기존 천하운수/ABC 기능을 유지하면서 CLEVER 통합관리에서 회사를 초대, 승인, 삭제 보관, 복구하고 회사별 탭 노출을 관리한다.

## 추가된 기능
- 통합관리 `회사 관리` 탭
- 회사 초대 링크 생성: `/company-signup/<token>`
- 대표 신청 승인/거절
- 회사별 추가 탭 ON/OFF
- 삭제 회사 30일 보관 및 복구
- 새 회사 정산 페이지: `/company/<회사코드>/...`
- 기존 회사 로그인 화면의 회원가입 버튼 제거

## 배포 순서
1. 백업을 먼저 만든다.
2. 백엔드 코드를 배포한다.
3. 앱 서버 재시작 전에 마이그레이션을 적용한다.
   - `python manage.py migrate accounts`
4. 백엔드 앱 서버를 재시작한다.
5. 프론트엔드 빌드 결과물을 배포한다.
6. 운영 smoke test를 실행한다.

## 운영 확인
- `clever_admin`으로 `/portal/companies` 진입
- `cheonha`, `abc`가 기존 활성 회사로 보이는지 확인
- 기본 회사 삭제 버튼이 비활성/차단되는지 확인
- 테스트 회사 초대 링크 생성 후 링크 화면 진입 확인
- 대표 신청 후 회사 관리 탭에서 승인/거절 버튼 확인
- 승인 후 `/company/<code>/login` 로그인 가능 여부 확인
- 기본 탭: 배차표 업로드, 배송원 관리, 조관리 노출 확인
- 추가 탭 ON/OFF 후 좌측 메뉴 노출 변경 확인
- 기존 `/cheonha` 주요 화면과 API smoke test 확인

## 주의
- 이번 변경은 DB schema 변경이 있으므로 운영 중에는 마이그레이션과 앱 재시작 순서를 지킨다.
- 회사 삭제는 실제 데이터 삭제가 아니라 `DELETED` 상태와 30일 복구 기한만 기록한다.
- `cheonha`, `abc` 기본 회사는 실수 방지를 위해 삭제를 차단한다.
